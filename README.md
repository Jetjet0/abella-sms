# Scholarship Management System
A Laravel 10 based system for managing scholarship applications and records.

## Project Feature List (Midterm Task #1)

### 1. Main Feature: Authentication
* **Actions:**
    * 1.1 Register
    * 1.2 Login
    * 1.3 Logout

### 2. Main Feature: Manage Applicants
* **Sub-Feature:** Applicant Records
    * **Actions:**
        * 2.1.1 Get/Display Applicant Data
        * 2.1.2 Add Applicant
        * 2.1.3 Edit Applicant
        * 2.1.4 Delete Applicant

### 3. Main Feature: Manage Scholarships
* **Sub-Feature:** Scholarship Records
    * **Actions:**
        * 3.1.1 Get/Display Scholarships
        * 3.1.2 Add Scholarship
        * 3.1.3 Edit Scholarship
        * 3.1.4 Delete Scholarship

### 4. Main Feature: Application Management
* **Sub-Feature: Student Actions**
    * 4.1.1 Submit Application
    * 4.1.2 View Application Status
* **Sub-Feature: Admin Actions**
    * 4.2.1 Approve Application
    * 4.2.2 Reject Application
